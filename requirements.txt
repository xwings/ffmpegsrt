# Translation runs through kerness, which is a Rust extension and so has to be
# built rather than merely put on sys.path. It is not a PyPI dependency — it
# ships as the submodule at vendor/kerness — so install it separately, with a
# Rust toolchain (rustc 1.88+, https://rustup.rs) present:
#
#     git submodule update --init --recursive
#     pip install ./vendor/kerness/bindings/python
#
# Transcription alone needs none of this.

# For --device cuda, also install the CUDA 12 runtime libraries. They are
# separate from the NVIDIA driver and CTranslate2 cannot find them otherwise:
#
#     pip install nvidia-cublas-cu12 nvidia-cudnn-cu12
#
# Left out of this file because they are ~1 GB and useless on a CPU-only box.
